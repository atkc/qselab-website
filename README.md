# Quantum Systems Engineering Group website

A light, static research-group website built with Next.js and exported for GitHub Pages.

## Pages

- Homepage with news, four research themes, recent publications, people and contact
- Four shareable research detail pages
- Searchable and tag-filtered publication archive
- News and media archive

## Local development

```bash
npm ci
npm run dev
```

For the same static export used by GitHub Pages:

```bash
npm run build:pages
```

The generated site is written to `out/`. See `CONTENT_GUIDE.md` for routine updates.

## Previous website archive

The complete former static website is preserved in `archive/legacy-site/`. It is retained for reference and is not used by the current GitHub Pages build.
